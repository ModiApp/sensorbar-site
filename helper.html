🌡 Temperature Sensor Helper

Enable real-time CPU and GPU temperature monitoring in SensorBar.

SensorBar runs in the App Sandbox for security, which means it can't directly read hardware temperature sensors (SMC). The SensorBarHelper is a lightweight background service that reads sensor data and passes it to the app.

⬇ Download SensorBarHelper

Installation

  1. Download and unzip SensorBarHelper.zip
  2. Open Terminal
  3. Navigate to the unzipped folder: 
    cd ~/Downloads/SensorBarHelper
  4. Run the install script: 
    sudo ./install.sh
  5. Restart SensorBar — temperature sensors will appear automatically
Why sudo? The helper needs root access to read hardware temperature sensors via the SMC (System Management Controller). It runs as a LaunchDaemon — a standard macOS background service managed by the system.

What gets installed

  • /usr/local/bin/SensorBarHelper — the helper binary
  • /Library/LaunchDaemons/com.ikeybenz.sensorbar.helper.plist — auto-start config

Uninstall

To remove the helper completely:

sudo ./uninstall.sh

Or from any terminal:

sudo launchctl unload /Library/LaunchDaemons/com.ikeybenz.sensorbar.helper.plist
sudo rm /usr/local/bin/SensorBarHelper /Library/LaunchDaemons/com.ikeybenz.sensorbar.helper.plist

Compatibility

Universal binary — works on both Apple Silicon and Intel Macs. Requires macOS 13 (Ventura) or later.
